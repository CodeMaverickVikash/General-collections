# Recommended VS Code Extensions

Curated list of high-productivity extensions for VS Code:

## Code Quality & Formatting
- **Prettier - Code Formatter** – Consistent automatic code formatting across projects.
- **ESLint** – Real-time linting and error detection for JavaScript and Node.js.
- **Document This** – Generates detailed JSDoc comments for JavaScript and TypeScript functions.
- **Code Spell Checker** – Catches spelling errors in source code, variable names, and comments.

## Language & Framework Support
- **Angular Language Service** – Autocomplete, error detection, and navigation in Angular templates.
- **angular2-switcher** – Quick navigation between `typescript`, `template`, `style`, and `test` files.
- **Tailwind CSS IntelliSense** – Autocomplete, syntax highlighting, and linting for Tailwind utility classes.
- **Bootstrap Intelligence** – Autocomplete for Bootstrap 5 classes.
- **Language Support for Java™ by Red Hat** – Full Java language tooling.
- **Json2ts** – Converts clipboard JSON into TypeScript interface definitions.

## Git & Version Control
- **GitLens — Git Supercharge** – Seamless inline blame annotations, repository visualization, and history.
- **Git History** – View commit history, compare files, and inspect branch branches visually.

## Preview & Live Development
- **Live Server** – Local development server with live reload for static and dynamic web pages.
- **Live Preview** – Embedded browser preview directly inside VS Code.
- **CSS Peek** – Jump directly to CSS ID and class definitions from HTML files.
- **Code Runner** – Run code snippets or files for multiple languages without leaving the editor.
- **Thunder Client** – Lightweight REST API client extension inside VS Code (Postman alternative).

## HTML & Tag Helpers
- **Auto Close Tag** – Automatically adds closing HTML/XML tags.
- **Auto Rename Tag** – Renames paired HTML/XML tags in sync.
- **Auto Complete Tag** – Combined autocomplete and auto-closing tag features.
- **Google Fonts Import** – Browse and insert Google Fonts `<link>` or `@import` rules easily.

## Themes & UI
- **Material Icon Theme** – File and folder icons for cleaner workspace navigation.
