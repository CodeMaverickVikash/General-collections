# VS Code Recommended Settings (`settings.json`)

Recommended configuration snippets for `settings.json`:

```json
{
  "editor.fontSize": 16,

  // Enable React JSX autocomplete with Emmet
  "emmet.includeLanguages": {
    "javascript": "javascriptreact"
  },

  // Editor group & tab behaviors
  "workbench.editor.closeEmptyGroups": false,
  "workbench.editor.enablePreview": false
}
```
