# VS Code Quick Settings & Shortcuts

Quick reference for essential editor behaviors and shortcuts:

| Setting / Feature | Description | Setting Path / Shortcut |
| :--- | :--- | :--- |
| **Close Empty Groups** | Automatically closes an editor group when its last tab is closed | `Workbench › Editor: Close Empty Groups` |
| **Enable Preview** | Toggles whether files opened from the sidebar appear in temporary preview tabs | `Workbench › Editor: Enable Preview` |
| **Minimap Options** | Configure visibility and position (`right` or `left`) of the code minimap | `Editor › Minimap: Enabled` / `Minimap: Side` |
| **Toggle Sidebar** | Quickly show or hide the primary sidebar | <kbd>Ctrl</kbd> + <kbd>B</kbd> |
